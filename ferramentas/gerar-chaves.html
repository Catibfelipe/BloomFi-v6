🦉 Gerar chaves do servidor BloomFi

Esta página roda só no seu computador (nada é enviado para a internet). Gere as chaves uma única vez e cole cada uma no Netlify em Site configuration → Environment variables.

Guarde as chaves num lugar seguro (ex.: gerenciador de senhas) e faça uma cópia. Não mande para ninguém. Nunca troque o APP_SECRET depois do lançamento: ele protege as contas, e sem ele ninguém consegue entrar. Se trocar a LICENSE_PRIVATE_JWK, o app pede uma licença nova sozinho; se trocar a VAPID_PRIVATE_JWK, cada pessoa liga os lembretes de novo.
